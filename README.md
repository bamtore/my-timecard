# 勤怠打刻アプリ

スマホのボタン一つで **出勤・休憩・退勤** を記録できるアプリです。
記録は自動で **Googleスプレッドシート** と **Googleカレンダー** に保存されます。

---

## 導入手順（所要時間 約20分）

やることは3つだけです。

| | やること | 使うもの |
|---|---|---|
| ① | 記録の保存先をつくる | パソコン（Google） |
| ② | アプリの画面を公開する | パソコン（GitHub） |
| ③ | スマホに入れる | スマホ |

> 💡 途中で **「URL」** と **「トークン（合言葉）」** の2つが出てきます。
> ③で使うので、メモ帳などにコピーしておいてください。

---

### ① 記録の保存先をつくる（Google）

**1. スプレッドシートを作る**
- [Googleスプレッドシート](https://sheets.new) を開く（新しいシートが作られます）
- 左上の名前を「勤怠記録」などに変更

**2. プログラムを貼り付ける**
- メニューの **「拡張機能」→「Apps Script」** をクリック
- 最初から書いてある文字を **全部消して**、`gas/Code.gs` の中身を **全部コピーして貼り付け**
- 上の 💾（保存）ボタンを押す

**3. 準備を実行する**
- 上のプルダウンで **`setup`** を選んで **「▷ 実行」** を押す
- 「承認が必要です」と出たら、次のように進めます
  1. 「権限を確認」→ 自分のGoogleアカウントを選択
  2. 「このアプリは Google で確認されていません」と出たら
     左下の **「詳細」→「（安全ではないページ）に移動」**
     ※ 自分で作ったプログラムなので問題ありません
  3. **「許可」**
- 下に出る「実行ログ」の **`APIトークン: xxxxxxxx…`** の部分をコピーして保存
  → これが **トークン** です 🔑

**4. 公開する**
- 右上の **「デプロイ」→「新しいデプロイ」**
- 「種類の選択」の ⚙ →  **「ウェブアプリ」**
- 次のように設定して **「デプロイ」**
  - 次のユーザーとして実行：**自分**
  - アクセスできるユーザー：**全員**
- 表示された **ウェブアプリのURL**（`https://script.google.com/…/exec`）をコピーして保存
  → これが **URL** です 🔗

✅ ここまでで、Google側の準備は完了です。

---

### ② アプリの画面を公開する（GitHub）

**1. GitHubに登録**
- [github.com](https://github.com) でアカウントを作成（無料）
- おすすめ設定：右上アイコン →「Settings」→「Emails」→ **「Keep my email addresses private」にチェック**
  （メールアドレスが公開されるのを防げます）

**2. リポジトリ（保管場所）を作る**
- 右上の **「＋」→「New repository」**
- Repository name：好きな名前（例：`my-timecard`）
- **Public** を選んで **「Create repository」**

**3. ファイルをアップロード**
- 作ったページの **「uploading an existing file」** をクリック
- このフォルダの中身（`docs` フォルダ・`gas` フォルダ・`LICENSE`・`README.md`・`.gitignore`）を
  **まとめてドラッグ＆ドロップ**
- 下の **「Commit changes」** を押す

**4. 画面を公開する**
- リポジトリの **「Settings」→ 左メニュー「Pages」**
- 「Branch」を **`main`**、その横のフォルダを **`/docs`** にして **「Save」**
- 1〜3分待ってページを再読み込みすると、上に
  **`https://ユーザー名.github.io/リポジトリ名/`** と表示されます
  → これが **アプリのアドレス** です 📱

✅ ここまでで、アプリの公開は完了です。

---

### ③ スマホに入れる

**1. アプリを開く**
- スマホで ②-4 の **アプリのアドレス** を開く
  （自分宛てにメールやLINEで送ると楽です）

**2. 接続設定**
- 設定画面が出るので、①でメモした2つを貼り付けて **「保存」**
  - GAS ウェブアプリ URL → **URL** 🔗
  - APIトークン → **トークン** 🔑
- 「未出勤」と表示されれば成功です 🎉

**3. ホーム画面に追加**
- **iPhone**：Safari の下にある 共有ボタン（□↑）→ **「ホーム画面に追加」**
- **Android**：Chrome 右上の ︙ → **「ホーム画面に追加」** または **「アプリをインストール」**

✅ ホーム画面の緑の時計アイコンから、いつでも打刻できます。

> ⚠ URLとトークンを送ったメールやメッセージは、設定が終わったら削除しておくと安心です。

## 使い方

| 今の状態 | 大きい丸ボタン | 下のボタン |
|---|---|---|
| 未出勤 | **出勤** | – |
| 勤務中 | **退勤** | ☕ 休憩する |
| 休憩中 | **休憩終了** | 退勤する |

### 記録される場所
- **スプレッドシート「勤怠記録」**：1日1行（日付・出勤・退勤・休憩・実働）
- **スプレッドシート「打刻ログ」**：すべての打刻履歴
- **Googleカレンダー**：勤務時間が「💼 勤務 8時間0分」、休憩が「☕ 休憩」として入ります

---

## 困ったときは

| こんなとき | どうする |
|---|---|
| 「認証に失敗しました」と出る | 右上の ⚙ を押して、トークンを貼り直す |
| 「通信エラー」と出る | ⚙ でURLを確認（最後が `/exec` になっているか） |
| 状態がおかしい（出勤してないのに勤務中など） | Apps Script で `resetState` を選んで ▷ 実行 |
| トークンを他人に知られたかも | Apps Script で `regenerateToken` を実行 → 新しいトークンをスマホに設定し直す |
| プログラムを変更した | 「デプロイ」→「デプロイを管理」→ ✏ →「バージョン：新バージョン」→「デプロイ」 |

## 公開範囲について
- GitHubで公開されるのは **プログラムだけ** です。
- 勤怠データは **あなたのGoogleアカウントの中だけ** に保存されます。
- URLとトークンは **スマホの中だけ** に保存されます。**GitHubには絶対に書かないでください。**
- アプリの画面は検索結果に出ないように設定済みです。画面を開かれても、トークンがなければ何もできません。

## 上級者向け

### カスタマイズ（`gas/Code.gs` 冒頭の `CONFIG`）
- `CALENDAR_ID`：勤怠専用カレンダーに書き込みたい場合に、カレンダーIDを指定
  （Googleカレンダーの設定 →「カレンダーの統合」に記載）
- `SPREADSHEET_ID`：スプレッドシートと独立したスクリプトにする場合に指定

### clasp で GAS も GitHub から管理
[clasp](https://github.com/google/clasp)（Google公式CLI, Apache-2.0）を使うと、コマンドで `gas/` をアップロードできます。
```
npm i -g @google/clasp
clasp login
clasp clone <スクリプトID> --rootDir gas
clasp push
```
`.clasp.json` / `.clasprc.json` は `.gitignore` 済みです。
